# 入口撕票交互改造方案

日期：2026-11-04。对象：`huijie-space` 的中英文入口页。

参考：[泽轩604入口](https://demo.zexuan604.com/)。方案阶段读取参考站公开 HTML、CSS、脚本及本地代码；未进行参考站实时拖动或逐帧视觉验收。以下保留方案内容，实施状态见文末。

## 判断

可以改，现有结构已经把票面 `.ticket-main` 与票根 `.ticket-stub` 分开，无需重做入口。推荐延续米白、森林绿、条码和 HJ. 编号，改好悬停、纸张分离与跳转时机。

截图中的组件更准确地说是撕车票票根。参考站源码实现的是悬停翘起、点击旋转脱落，没有拖动手势或真实纸张物理模拟。

## 已确认的差异

| 环节 | 参考站实现 | 你当前的实现 | 修改方向 |
| --- | --- | --- | --- |
| 悬停 | 整票抬起，票根独立旋转约 3.5°、横移 3px | 主要是整票移动；票根没有独立预动作 | 先让票根轻翘，提示这里可以撕 |
| 纸张结构 | 票面、票根分别用 mask 裁出上下缺口，父层用 drop-shadow 描边和投影 | 父层仍有完整矩形背景、边框、box-shadow；缺口由票根伪元素覆盖 | 分别画两张纸，分离后不留下矩形底板或连接阴影 |
| 脱落 | 以左侧中央为轴，从悬停姿态转到约 32°并下落 | 以左上角为轴，从 0°开始，最终转到 24° | 点击接续翘起姿态；增加轻微弯折感 |
| 时机 | CSS 520ms、脚本 420ms 后导航 | 同样是 CSS 520ms、420ms 后导航 | 修正两边都有的截断：动画完成再导航，另设超时兜底 |
| 动画叠加 | 入场使用单独的 translate 属性等方式 | 入场动画以 both 保留 transform，悬停也写 transform | 分离入场、整票抬起、票根旋转，避免互相覆盖 |

## 推荐效果：轻翘 → 撕开 → 脱落 → 进入

静止时保持当前排版，票根沿虚线连接；提示只用低调的“点击撕票，进入主页”或“点击撕票，开车探索”。整张票仍可点击，不要求访客精确命中票根。

桌面悬停约 220ms 内，整票上抬 3–4px、投影稍加深；票根围绕左侧中央旋转约 3°、向右移 3px。移开即复位，键盘聚焦提供对应反馈。仅在精确指针且支持 hover 的设备启用鼠标悬停。

点击后的建议时间表如下，数值为初始调校目标：

| 时间 | 画面 |
| --- | --- |
| 0–100ms | 票根略向右拉紧，票面轻微回压，保留已翘起的姿态 |
| 100–260ms | 票根转至约 10–14°，沿分隔线从上到下逐渐露出缝隙；增加很轻的折面明暗 |
| 260–480ms | 票根完全脱离，向右下移动约 50–70px / 100–140px，转至约 28°并淡出；票面留下细小锯齿边 |
| 约 500ms | 脱落结束后进入所选页面；不增加额外等待 |

相较参考站，建议增加的是逐步裂开的缝隙、轻微折面明暗及断口；这些不是本次已观察到的原站功能。先用 CSS mask / clip-path、渐变和 transform 实现视觉近似，不需要引入物理引擎。

## 实现范围

- `app.js`：保留原生链接；需要时增加纯装饰层；以票根动画完成事件触发导航，过滤动画名和目标节点，并提供有限时长兜底。统一管理计时器，防止重复点击、返回页面后旧回调误触发。
- `styles.css`：拆开票面与票根的底色、缺口、边框和投影；去掉父层完整矩形底板；分离入场与悬停的动画属性；新增翘起、分离、断口和脱落样式。
- 入口中英文提示：如采用新提示，同步更新 `content.js`，避免文字挤压条码与编号。

手机继续采用点击撕票，缩小横向位移，避免脱落时产生页面横向滚动。保持现有手机直接入口及驾驶入口显示规则。

减少动态效果时直接导航；保留 Tab / Enter、修饰键新标签打开、记住选择和浏览器返回恢复。音效不列入本轮默认效果。

## 可选的第二步：拖动撕票

只有希望强调可玩性时再增加：按住票根向右下拖动，旋转及裂口随拖动进度变化；不足阈值松手则回弹，越过阈值后完成脱落并进入。整票点击继续可用。

这一版要额外处理手势取消、点击与拖动区分、触摸滚动和指针捕获，建议先完成点击版再决定。参考站当前源码不包含这套拖动行为。

## 验收

1. 悬停时票根独立翘起；入场结束后仍然有效，离开能归位。
2. 点击时先看到分离再看到脱落，随后才跳转；没有完整矩形底板残留。
3. 米白与绿色两张票都不出现接缝色差、缺口错位或方形连接阴影。
4. 连点只触发一次导航；从目标页后退时两张票和计时器恢复正常。
5. 中英文、窄屏和键盘均可进入；手机动画不产生横向滚动；减少动态效果时立即进入。

完成后运行现有检查与构建，并在真实浏览器对照悬停、点击、后退和手机宽度。DOM 模拟通过不能替代视觉验收。

## 实施记录 · 2026-11-04

点击版已写入本地代码，未提交或推送远端：

- 票面、票根分别裁出圆形缺口及 2px 锯齿边，各自投影，移除整票矩形底板。
- 鼠标悬停或键盘聚焦时票根翘起；点击从当前姿态接续动画，绕左下连接处逐渐打开缝隙，增加折面明暗、票面轻微回压及向右下脱落。
- 脱落动画为 520ms，以对应票根的 `animationend` 导航；800ms 兜底，防止样式未加载时无法进入。
- 重复点击在导航期间拦截；页面离开与返回时清理计时器、忙碌状态和动画。减少动态偏好在点击时及动画中均生效。
- 入场改用独立的 `translate`，不再用保留终态的入场 `transform` 覆盖悬停；手机缩小脱落位移和角度。中英文增加撕票提示。

验证：`npm run check` 通过并构建 16 个路由；44 项 DOM 状态场景分别在 `/` 与 `/hj/` 路径通过，覆盖动画完成、无关动画事件、连点、超时兜底、返回取消、动态偏好变化与双语跳转。本地中英文入口 HTTP 返回 200。

本轮浏览器扩展服务不可用；原生 Chrome 控制多次因用户正在改变窗口状态而中止，因此未完成桌面/手机最终视觉验收，未将 DOM 测试当作画面验收。本地预览：<http://127.0.0.1:4173/>。

### 未点击时保持完整 · 2026-11-04

用户反馈未点击就像已经撕开。修正了上一版提前显示分离状态的问题：

- 移除悬停及键盘聚焦时的票根独立位移和旋转，只保留整票轻微抬起。
- 静止时使用整张票的统一轮廓阴影，票面和票根各自的阴影只在点击后启用，避免分隔线上提前出现黑色裂缝。
- 锯齿断口只在 `.is-tearing` 状态启用，未点击时接缝保持平直，仅显示原有虚线。
- 绿色纸面使用纵向渐变，两片同高纸张接缝处颜色一致。

重新构建及检查通过，CSS 解析无警告；44 项 DOM 状态场景通过。本轮再次尝试浏览器预览，控制服务仍不可用，因此尚未完成最终视觉实测。

### 票根纸面宽度修复 · 2026-11-04

用户再次反馈未贴合。本轮通过原生 Chrome 截图确认了实际空隙：旧 `.ticket-stub` 的 `align-items:center` 仍作用于新加的 `.ticket-stub-face`，导致纸面按内容宽度居中缩窄，票面右边与票根纸面之间留出可见空白。前次修复未消除这个布局原因。
