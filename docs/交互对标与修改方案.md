# Huijie's Space：交互对标与修改方案

检查日期：2026-11-03。参考站：[入口](https://demo.zexuan604.com/)、[主页](https://demo.zexuan604.com/home/)、[驾驶](https://demo.zexuan604.com/drive/)。

入口句子已修改为：

> 选择一条路线，走进我的个人小镇：直接看主页，或者开车探索。

以下表格保留实施前的对比，便于追溯。本轮已按用户确认实施，状态见文末；未上传 GitHub。

## 结论与证据范围

当前版覆盖了主要页面与驾驶能力，但未达到交互细节的一比一还原。缺口集中在互动网点标题、小镇选中反馈、导航与滚动联动、车票撕角及驾驶信息卡。

本次重新读取参考站当前公开 HTML、CSS、脚本，逐项对照本地 `app.js`、`styles.css` 和驾驶引擎；通过可见浏览器重新核对入口、主页和文案。浏览器扩展的 DOM 连接两次超时，之后改用原生浏览器界面读取。下表中的具体算法、定时边界与历史恢复差异属于源码确认，不代表本轮逐帧录制了全部动画。驾驶主体使用此前已适配的同一引擎，上轮实测记录见 `../qa/验收记录.md`。

## 建议实施顺序

### 第一批：先让最明显的互动接近参考站

1. 修复语言切换位置、返回入口状态等基础行为。
2. 加入吸顶导航和阅读进度。
3. 恢复三处网点标题的聚合、指针排开与回弹。
4. 恢复票根撕开与可靠的进入过渡。
5. 调整首页为个性化昼夜图与精确交互层，补上小屋高亮和地址联动。
6. 将驾驶居中弹窗调整为侧边纸卡。
7. 处理窄屏、减少动态偏好和故障降级。

第一批完成后提供桌面与手机宽度预览，重点对照「移动鼠标、点击、滚动、后退、切语言」五类动作。

### 第二批：统一动效节奏与细节反馈

增加文字条滚动联动、分层入场、页面过渡、盖章、复制反馈、昼夜边界同步，以及驾驶卡内的公众号复制。恢复手机双语导航的一致性。

### 后续有资料时启用

项目卡片动效、文章阅读/复制、真实社交平台卡片，随真实资料补充再接入。

## 验收标准

- 入口、首页、页脚标题：指针经过后有局部反馈，离开后完整复原；小屏没有横向溢出。
- 车票：票根先动，再进入；修饰键打开新标签和浏览器后退都正常。
- 六栋建筑：高亮、标签与地址一致；点击正确栏目；Tab / Enter 也可完成浏览。
- 吸顶导航：正文滚动时可用；进度条与阅读位置对应；锚点标题无遮挡。
- 双语：从文章或联系区域切语言后仍在同一栏目，不回到顶部。
- 驾驶：侧卡不覆盖全景；关闭后恢复驾驶；自动导览、地图选点和键盘接管可连续使用。
- 公众号：主页与驾驶卡都能复制；失败时给出可手动复制的名称。
- 动态偏好与宽度变化：页面保持可访问，3D 不在不可见或不支持的状态下继续占用资源。
- 项目、经历和文章维持现有资料边界。
